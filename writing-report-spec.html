Select — Popout list

Trigger is 48–56px tall, 8px radius, 1px #77767A border, white fill, chevron rotating 180° on open. The list is the Angelou Popout: 8px radius, 8px block padding, 40px rows, 0 4px 12px rgba(29,29,29,0.16), 0 0 2px rgba(29,29,29,0.08), 4px below the trigger, 336px scroll cap. Selected row is #F7F8F8 with a 4px Blue 700 marker; text inset stays 16px either way. Every dropdown on the page is one shared PopoutSelect component — native selects can't be styled, so the list is rebuilt with full keyboard support (arrows, Home/End, Enter, Escape) and only one open at a time. Picking an option commits the value and closes the list; the select cancels the option click's default so it can't be forwarded back to the trigger and reopen.

Toggletips & tooltips

Every "i" icon mounts the Angelou Toggletips component in the dark variant — Neutral 700 fill, white type, 16% white ring, 8px radius, arrow pointing at its trigger. Toggletips open on click and stay open until dismissed, the close button, or Escape; triggers carry a 24px minimum tap area. Chart points and distribution segments keep plain hover tooltips, since those are data readouts rather than help content.

Volume metrics count work students submitted. Anything labeled score counts only work that has been scored against a rubric, so scored totals are usually lower than submitted totals. Chart hover (not a toggletip) March 2027 — 71% of points possible

Tracked metric bars

Label left, value right-aligned on the same line, then a full-width 12px #EAEBEC track carrying the fill below it. The track runs the full column on every row, so the bars read against a common 100% rather than against each other's endpoints. Each metric owns a color — Assignments #8B1EA4, Submissions #0F3FDE, Feedback requests #0A6EFA, Teacher comments #0F8670 — reused wherever that metric appears. Same construction for submissions by rubric and the submitted-writing bars. All counts derive from one per-student submission total, so the section reconciles: the by-rubric bars sum to the submissions figure, and the selector count matches the student table.

Score distribution bar

40px tall, one segment per score point, 2px white gaps, 32px caps on the outer ends. Segments flex proportionally rather than taking fixed percentage widths, so every row ends flush even when a band is narrow. Hover fades siblings to 55% and shows the share for that score.

Rubrics carry their own scales — 0–2, 0–4, 0–8 — so nothing about the bar is fixed to a scale. Color is sampled from a five-stop ramp (#C8102E, #F16E00, #E8AB14, #3ECF9A, #0F8670) interpolated across however many points the criterion has, so low→high reads the same at any length. Numeral ink is whichever of Neutral 700 or white has the higher WCAG contrast against its own band. Score labels are dropped on bands under 7% of the row (4% above six segments) rather than crowding. Rubric performance renders one table per point scale present in the rubric — "Rubric criteria — scored 0 to 8", "…0 to 2" — built from the distinct ceilings its criteria declare.

Section header with disclosure

Every section heading carries a toggletip stating what that section counts. Volume metrics count submitted work; anything labeled score counts scored work only, so the two can legitimately disagree — the disclosure lives in each section's own words rather than as one page-level note.

Rubric performance Score distribution across every scored submission for the selected rubric. Work that was turned in but not yet scored is excluded, so these counts can be lower than submitted writing.

Rubric score growth chart

SVG line chart with month bands, points at band centers, a grey #F2F3F4 hover band, and dashed 5 9 spans confined to months with no data. Every criterion is plotted as percent of the points possible for that criterion, so a 0–2 criterion and a 0–4 criterion share one axis honestly. The axis fits the data — bounds snap to a round step across four intervals with a 40-point minimum window, and 0 only appears when the data reaches it. Y axis is a 1px #B7B7B7 rule with 6px ticks; tick labels and the axis title are HTML positioned over the SVG so they render at a true 13px at any width. On load the lines wipe in left to right via a clip rect, with the axis fixed from the first frame. A category select above the chart narrows it to a single criterion or plots all of them together.

Design bar

Prototype scaffolding only — not a product surface. Four levels: the exploration name as static text, then a pill holding audience → page → variant dropdowns. Audience jumps to that audience's first page, page navigates within the audience, variant persists across pages. A dot plus phase label shows review status read-only; the timestamp is hardcoded per page and means when that page last changed, never when it loaded. The "Design spec" link appears only on pages that have one. Documented in Design bar snippet.md for reuse.
